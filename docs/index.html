Proposta

Uma base para trocar de marca sem reescrever tela

O Rendra separa a marca do componente: você muda cores, modelo, nome e logotipo, e o sistema inteiro acompanha.

01

Tokens em três camadas

Modelo, paleta e sistema. Trocar a marca são 4 cores, um degradê, um modelo, o nome e o logotipo, sem tocar em componente.

T×C

3 modelos e 4 paletas

Safira, Equilíbrio e Aurora, com as paletas Safira, Equilíbrio, Aurora e Ardósia. Cada combinação tem um código, como T2-C3.

50+

Componentes acessíveis

Botões, formulários, tabelas, modais, gavetas, gráficos, calendário, kanban, chat e o AppShell, com foco visível e toque mínimo de 44x44.

360

Mobile primeiro

Escrito para 360 px: a tabela vira cartões, o menu lateral vira gaveta e a navegação ganha uma barra inferior. Nada depende de hover.

Instalação

Rode em poucos comandos

Pré-requisito: Node.js 22 ou mais recente. Escolha o caminho: clonar o repositório inteiro, instalar o pacote, ou trazer um componente por vez.

Clonar e rodar

git clone https://github.com/bsmagalhaes/rendra-ui-web meu-sistema
cd meu-sistema
npm install
npm run dev

Como pacote npm

npm install @rendra-ui/web react react-dom radix-ui

Um componente por vez (registry do shadcn)

npx shadcn@latest add https://bsmagalhaes.github.io/rendra-ui-web/r/select.json

CLI: catálogo de códigos

npx @rendra-ui/web codigos

Perguntas frequentes

Dúvidas comuns

O que é o Rendra Design System?

É um design system e boilerplate React (Vite, TypeScript, Tailwind CSS v4, Radix e shadcn/ui). Traz mais de 50 componentes, o AppShell com menu lateral e superior, telas de exemplo, 3 modelos de marca e 4 paletas, para começar um sistema novo ou migrar o layout de um existente.

Posso usar em projeto comercial?

Sim. A licença é MIT: você pode usar, copiar, alterar e distribuir, inclusive em projetos comerciais, mantendo o aviso de copyright e o arquivo LICENSE. O crédito "Feito com Rendra" na tela é opcional.

Como troco a marca do sistema?

Com 4 cores, um degradê, um modelo, o nome e o logotipo, sem mexer em componente. Cada combinação de modelo, paleta e menu tem um código, como T2-C3-M5, que você informa no briefing.

Posso usar só alguns componentes?

Sim. Instale o pacote npm @rendra-ui/web ou traga um componente por vez pelo registry do shadcn, com npx shadcn@latest add e o endereço do componente em r/ neste site.

Como uso com uma IA de código?

Cole o link do repositório numa IA de código (Claude Code, Codex, Cursor, Gemini ou Copilot). O AGENTS.md é o ponto de entrada: a IA conduz o briefing, planeja em etapas e roda os testes.

Os componentes são acessíveis?

Foram feitos para isso: toque mínimo de 44x44, foco visível, nada que dependa de hover e verificação automática com axe (WCAG 2.1 AA) em todas as telas, nos três modelos, no claro e no escuro.
